How it works

Three steps, one promise.

From raw pixels to natural-language insight — no glue code required.

01 / Select

Pick a region

A native transparent overlay lets you drag-select any area of the screen. Esc to cancel, right-click to abort.

02 / Analyze

Send to vision AI

The cropped JPEG is base64-encoded and posted to the Responses API with your prompt. Any compatible vision model works.

03 / Result

Get the analysis

Receive the model's text response alongside the saved screenshot path, dimensions, and base64 payload.

Usage

One client, one call.

Create a client with credentials or env vars, then capture and analyze in a single await. Runs in the Electron main process.

main.ts 
// Electron main process
import { createClient } from "aicapture";

const client = createClient({
  credentials: {
    baseUrl: "https://ark.cn-beijing.volces.com/api/v3",
    apiKey: "YOUR_API_KEY",
    model: "doubao-seed-2-0-mini-260428",
    prompt: "Analyze this screenshot and summarize key UI and next steps.",
  },
  imgDir: "aicapture",
});

const { screenshot, analysis } = await client.captureAndAnalyze();

console.log(screenshot.imagePath);
console.log(analysis);
Client API

A small, predictable surface.

Four methods. Everything you need to capture, analyze, or both.

createClient(options?) Create a client with credentials, a config object, or env vars.
client.captureAndAnalyze(options?) Select a region, capture it, and run AI analysis in one call.
client.captureSelectedRegion(options?) Capture a selected screen region without invoking the model.
client.analyzeImage({ base64Image, mimeType }) Run analysis on an arbitrary base64 image you already have.
Configuration

Env vars, no boilerplate.

Drop a .env file in your project root and call createClient() with no arguments.

VariableDescription
ai_base_urlBase URL for the Ark Responses API
ai_api_keyAPI key for authentication
ai_modelVision model ID to invoke
AI_PROMPTPrompt sent alongside the image
