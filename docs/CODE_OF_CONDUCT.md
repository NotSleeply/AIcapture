# Code of Conduct

This project is committed to providing a friendly, safe, and respectful environment for everyone.

## Our Standards

- Be respectful, patient, and considerate.
- Assume good intent and give constructive feedback.
- Be inclusive and welcoming to newcomers.
- Avoid harassment, discrimination, or personal attacks.

## Reporting

If you experience or witness unacceptable behavior, please report it to the maintainers. For private reporting, use GitHub Security Advisories or contact a maintainer directly.

## Enforcement

Project maintainers are responsible for clarifying standards and taking fair corrective action when needed.
